# Attack timing report

Generated by `LanternKnight --anim-report`. For each attack action the weapon tip (handslot.r, +Y 1.3 units)
is sampled every 1/120 s of clip time. *Swing* is the span where tip speed stays above 45% of its peak.
The anim maps in data/anims/ use these as `hit` / `hit_end` (clip seconds).
